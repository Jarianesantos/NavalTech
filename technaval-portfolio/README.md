# TechNaval Portfolio

Portfólio estático que apresenta:

* **Logo TechNaval** – SVG com gradientes, anéis criptográficos giratórios e a Cifra de César (ROT 3).
* **Descrição** – breve texto sobre o conceito e a aplicação em engenharia de software.
* **Deploy** – pronto para GitHub Pages (`git push` → Settings → Pages).

## Como publicar

```bash
# Clonar ou copiar os ficheiros para o seu repositório
git clone https://github.com/Jarianesantos/NavalTech.git
# ou simplesmente adicionar a pasta `technaval-portfolio` ao seu repo existente

git add .
git commit -m "Add TechNaval portfolio site"
git push origin main
```

Em seguida, no GitHub: **Settings → Pages → Source: main branch / /(root)**.  
O site ficará em `https://Jarianesantos.github.io/NavalTech/` (ou o nome que escolher).
